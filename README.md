# Berget Museum

A pictorial museum of the Berget family, from Levor Kvie (born 1590) in Flå to Turtle Lake, North Dakota.

Open `index.html` in a browser. It is a static site with no build step: the views are in `index.html`, family data is in `data/`, and photographs and records are in `img/`. Restored copies of old photographs are saved next to the originals with `-restored` at the end of the file name.

Sources are credited at the bottom of each view.
